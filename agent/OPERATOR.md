# Operator — Facebook-first autonomous worker

How an agent runs Social Lead Watcher for a tenant and reports dashboard activity.

## Inputs

- Tenant config: `tenants/<slug>/business.yaml` (local/private) or demo `tenants/demo/business.yaml`
- Page identity from app connection status (`agent_mode` for Facebook)
- Dedup file: `data/handled.jsonl` (local only)

## Autonomy model (honest)

| Layer | Who | Does |
|-------|-----|------|
| Expo app | User | Business config, drafts, dashboard, export/sync |
| `lead_watcher craft` | Brain | Classify + unique comment/DM variants |
| Agent / browser-as-Page | Operator | Actually open groups, post comment, try DM |

This is **not** official Meta unpaid group automation via Graph API.

## Cycle

1. `python -m lead_watcher craft --config … --text "…" --group "…"`
2. If `should_outreach` and under `max_outreach_per_run`:
   - Post `best_comment` as the **Page**
   - Attempt DM with crafted `dm` (note failure reasons; never invent success)
3. Dedupe: skip any `post_url` already in handled log
4. Emit activity events (JSON) for the dashboard — see schema below

## Activity event schema (dashboard)

```json
{
  "ts": "2026-09-21T19:00:00-07:00",
  "platform": "facebook",
  "action": "comment_posted",
  "classification": "strong",
  "need": "vinyl siding",
  "group": "Contractors of Seattle",
  "postUrl": "https://facebook.com/…",
  "detail": "optional short note"
}
```

Actions: `lead_found` | `comment_posted` | `dm_sent` | `skipped` | `platform_connected` | `watcher_paused` | `watcher_resumed`

Dashboard one-liners are generated by `lead_watcher.summarize.activity_one_liner`.
Daily subtitle: `lead_watcher.summarize.daily_rollup`.

**Public repo rule:** sanitize with `sanitize_activity_for_export` — no authors, no DM bodies, no raw personal snippets.

## Facebook posture

- Operate as connected **Page** (browser-as-Page / MasterFix-style playbook)
- Session stays in operator environment only
- Soft, helpful tone; rotate craft strategies — never identical spam

## Other platforms

Listed in the app (Nextdoor, Craigslist, Reddit) but **not smart yet** — stubs only. Do not pretend full autonomy there.
